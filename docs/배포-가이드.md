> Vercel: https://vercel.com/dashboard

## 배포 구조

```
로컬 PC (VS Code + Claude Code)
    │
    │ git push origin master
    ▼
GitHub (pinp10000-v1/pipin-homepage)
    │
    │ 자동 감지 (Webhook) — 약 1~2분
    ▼
Vercel (빌드 + 서버 호스팅)
    │
    │ CNAME / A 레코드
    ▼
Namecheap DNS
    │
    ▼
pip-biz.com (실제 운영 홈페이지)
```

---

## 1. 로컬 → GitHub

```bash
# 빌드 검증 먼저
npm run build
# ✓ Compiled successfully 확인

# GitHub에 올리기
git add .
git commit -m "feat: 기능 설명"
git push origin master
```

### 커밋 타입 규칙

| 타입 | 용도 |
|------|------|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `refactor` | 코드 정리 |
| `style` | 스타일만 수정 |
| `docs` | 문서 수정 |

## 2. Vercel 환경변수 설정

`.env.local`은 로컬 전용이라 배포에 포함되지 않습니다.  
아래 변수를 **Vercel 대시보드에 별도 등록**해야 합니다.

> Vercel → 프로젝트 → Settings → Environment Variables

| 변수명 | 값 | 필수 여부 |
|--------|----|----------|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://mbsunuudpdvzozmjoxtt.supabase.co` | 뉴스 기사 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `sb_publishable_PwBH-c3...` | 뉴스 기사 |
| `SMTP_HOST` | `smtp.gmail.com` | 문의 이메일 |
| `SMTP_PORT` | `465` | 문의 이메일 |
| `SMTP_USER` | `pinp10000@gmail.com` | 문의 이메일 |
| `SMTP_PASS` | Gmail 앱 비밀번호 | 문의 이메일 |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | 서비스 계정 이메일 | Google Sheets (선택) |
| `GOOGLE_PRIVATE_KEY` | 서비스 계정 키 | Google Sheets (선택) |
| `GOOGLE_SHEET_ID` | 스프레드시트 ID | Google Sheets (선택) |

⚠️ 환경변수 추가 후 **Redeploy** 필요 (Settings → Deployments → Redeploy)

## 3. Namecheap DNS 설정

> Namecheap → Domain List → pip-biz.com → Manage → Advanced DNS

Vercel 연결에 필요한 DNS 레코드:

| Type | Host | Value |
|------|------|-------|
| `A` | `@` | `76.76.21.21` (Vercel IP) |
| `CNAME` | `www` | `cname.vercel-dns.com` |

- 변경 후 전파 시간: 최대 48시간 (보통 수분~수시간)
- Vercel 도메인 등록: 프로젝트 → Settings → Domains → `pip-biz.com` 추가

## 접속 불가 진단 체크리스트

```
[ ] 1. Vercel 빌드 상태 확인
        → vercel.com/dashboard → 프로젝트 → Deployments
        → 빨간 FAILED 있으면 로그 확인

[ ] 2. Vercel 환경변수 등록 여부 확인
        → Settings → Environment Variables
        → NEXT_PUBLIC_SUPABASE_URL / ANON_KEY 있는지 확인

[ ] 3. 도메인 연결 상태 확인
        → Vercel → Settings → Domains → pip-biz.com
        → "Invalid Configuration" 표시 없는지 확인

[ ] 4. Namecheap DNS A 레코드 확인
        → @  →  76.76.21.21

[ ] 5. 도메인 만료 여부 확인
        → Namecheap → Domain List → 만료일 확인

[ ] 6. 로컬 빌드 테스트
        → npm run build
        → 에러 없으면 코드 문제 아님
```

## 배포 실패 시 복구 절차

```bash
# 1. 로컬 빌드 오류 확인
npm run build

# 2. 오류 수정 후 재배포
git add .
git commit -m "fix: 빌드 오류 수정"
git push origin master

# 3. Vercel에서 수동 재배포
# vercel.com/dashboard → 프로젝트 → Deployments → 최근 성공 배포 → Redeploy
```
